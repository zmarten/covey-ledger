30-Second Elevator Pitch

Covey Ledger is a rugged personal hunting log for serious upland sportsmen.
It tracks harvested birds, freezer inventory, and state-specific daily and possession limits — with hard server-side enforcement so nothing slips through.

Think: field ledger meets compliance engine.

Problem & Mission
The Problem

Upland hunters who travel across states must:

Track daily limits (per state, per species)

Track possession limits (multi-day, state-specific)

Manage freezer inventory

Avoid accidental violations

Most rely on memory, notes apps, or spreadsheets.

That’s risky.

The Mission

Deliver a dependable compliance-first hunting ledger that:

Prevents violations before they happen

Separates possession by state

Maintains accurate freezer accounting

Feels structured and authoritative

No ambiguity. No soft warnings.

Target Audience
Primary User

Solo upland hunter who:

Travels across multiple states

Self-processes birds

Freezes and consumes over time

Cares deeply about legal compliance

Secondary (Future)

Multi-state seasonal hunters

Conservation-minded sportsmen

Hunters auditing long-term harvest trends

Core Features
1. Dashboard — “Today in the Field”

Immediate situational awareness:

Active state selector

Today’s harvest (by species)

Remaining daily limit

Remaining possession capacity

Freezer totals (grouped by state of origin)

Warning tiers:

80% → Amber

100% → Red + hard block

Primary action: Log Birds

2. Harvest Entry Log

Fields:

Species

Quantity

State

Date (auto-filled)

Notes (optional)

On Save → Server-side compliance engine runs:

Step 1 — Daily Limit Check

Per species

Per state

Per calendar day

Step 2 — Possession Check

Possession formula (state-specific):

Total Harvested (state)
– Distributed (state)
– Consumed (state)
= Current Possession (state)

If exceeded:

Save blocked

Clear explanation shown

Exact remaining capacity displayed

3. State Regulations Page

Editable regulation table:

State

Species

Daily limit

Possession limit

Optional season dates

Each state maintains independent possession accounting.

Future:

Wildlife agency API auto-sync

4. End-of-Day Split Tool

Purpose: Allocate your retained birds from a group hunt.

Workflow:

View today’s harvest

Enter number of hunters

Adjust your retained share

System recalculates:

State-specific possession

Freezer totals

Only your retained birds affect your ledger.

5. Freezer Inventory

Structured table:

Total Birds in Freezer
